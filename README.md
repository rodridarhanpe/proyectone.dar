Invasion espacial.
Este juego esta en desarrollado en Python utilizando Pygame ,tiene como objetivo aprender programacion y su logica.
Tiene fallas en su funcionamiento que seran arregladas a la brevedad
caracteristicas:  
- Nave controlable por el jugador
- Enemigos en pantalla
- Disparo de proyectiles
- Imágenes y sonidos básicos
- Música de fondo
